# 🧪 UI-автотесты (Python)

Полуфинал дисциплины «Автоматизация тестирования 

Проект UI-автотестов для трёх страниц сайта [practice-automation.com](https://practice-automation.com/): **Calendars**, **Modals**, **Ads**.

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <https://github.com/vvdviktoria20-debug/practice-automation-tests>
cd automation-project
```

### 2. Создание и активация виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск тестов
```bash
# Все тесты
pytest -v

# Тесты одной страницы
pytest tests/test_calendars.py -v
pytest tests/test_modals.py -v
pytest tests/test_ads.py -v
```

### 5. Генерация и просмотр отчёта Allure
Требуется установленная Java (17+) и [Allure CLI](https://allurereport.org/docs/install/).
```bash
pytest --alluredir=allure-results
allure serve allure-results
```
Отчёт открывается в браузере автоматически: статусы тестов, шаги, скриншоты при ошибках.

## 🛠 Технологический стек
- **Python 3.12+**
- **Selenium WebDriver 4.x**
- **Pytest**
- **Allure Framework** (allure-pytest)
- **webdriver-manager** (автоматическая установка ChromeDriver)
- **Chrome** (с актуальной версией драйвера)
