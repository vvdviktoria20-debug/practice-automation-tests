# Автоматизация тестирования UI — practice-automation.com

Полуфинал, дисциплина «Автоматизация тестирования (Java, Python)». Стек: **Python + Selenium + Pytest + Allure**.

Проект автоматизирует три страницы сайта <https://practice-automation.com/> — **Calendars**, **Modals**, **Ads** — и пункт 5 задания (заполнение поля Message списком «Automation tools»). Подход — **Page Object Model**.

---

## Установка и запуск

### Что нужно заранее
- Python 3.10 или новее (проверка: `python --version` на Windows, `python3 --version` на Mac и Linux)
- Google Chrome
- Git (проверка: `git --version`)
- Для просмотра отчёта: Java 11+ и Allure CLI (проверка: `allure --version`)

> При установке Python на Windows поставьте галочку **«Add Python to PATH»**.
> ChromeDriver скачивается автоматически, вручную ставить не нужно. При первом запуске нужен интернет.

### Установка на Windows

1. Склонировать проект и перейти в папку:
   ```powershell
   git clone https://github.com/vvdviktoria20-debug/practice-automation-tests.git
   cd practice-automation-tests
   ```
2. Создать виртуальное окружение:
   ```powershell
   python -m venv venv
   ```
3. Активировать его:
   ```powershell
   venv\Scripts\activate
   ```
4. Установить зависимости:
   ```powershell
   pip install -r requirements.txt
   ```

Если PowerShell пишет, что выполнение скриптов запрещено, выполните один раз:
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
Если команда `python` не найдена, используйте `py`.

### Установка на Mac / Linux

1. Склонировать проект и перейти в папку:
   ```bash
   git clone https://github.com/vvdviktoria20-debug/practice-automation-tests.git
   cd practice-automation-tests
   ```
2. Создать виртуальное окружение:
   ```bash
   python3 -m venv venv
   ```
3. Активировать его:
   ```bash
   source venv/bin/activate
   ```
4. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Запуск тестов

Команды одинаковы на всех системах:

```bash
pytest                              # все тесты
pytest tests/test_calendars.py      # только Calendars
pytest tests/test_modals.py         # только Modals
pytest tests/test_ads.py            # только Ads
pytest tests/test_form_fields.py    # пункт 5: Automation tools → Message
```

По умолчанию открывается окно Chrome. Запуск без окна:
- Windows PowerShell: `$env:HEADLESS="1"; pytest`
- Windows cmd: `set HEADLESS=1 && pytest`
- Mac / Linux: `HEADLESS=1 pytest`

### Allure-отчёт

1. Запустить тесты с сохранением результатов:
   ```bash
   pytest --alluredir=allure-results
   ```
2. Открыть отчёт в браузере:
   ```bash
   allure serve allure-results
   ```

Установка Allure CLI:
- Windows: `scoop install allure`, либо скачать архив с <https://github.com/allure-framework/allure2/releases>, распаковать и добавить папку `bin` в PATH. Нужна Java (<https://adoptium.net>).
- Mac: `brew install allure` или `npm install -g allure-commandline`.
- Любая система с Node.js: `npm install -g allure-commandline`.

В отчёте видно, какие тесты запускались и с каким результатом, названия тестов, шаги внутри каждого теста и скриншот при падении (вложение `screenshot-on-failure`). Копия скриншота сохраняется в папку `screenshots/`.

### Частые проблемы
- **`python` или `pip` не найдены** — переустановить Python с галочкой «Add Python to PATH» или использовать `py`.
- **PowerShell запрещает активацию venv** — выполнить `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- **`ModuleNotFoundError`** — не активировано окружение. Активировать его и снова выполнить `pip install -r requirements.txt`.
- **Ошибка при скачивании ChromeDriver** — проверить интернет и обновить Chrome.
- **`allure` не найдена** — установить Allure CLI и Java, затем перезапустить терминал.

## Архитектура проекта

```
practice-automation-tests/
├── pages/                      # Page Object: описание страниц и действий на них
│   ├── base_page.py            # общие методы (найти, кликнуть, ввести) + Allure-шаги
│   ├── calendars_page.py       # страница Calendars
│   ├── modals_page.py          # страница Modals
│   ├── ads_page.py             # страница Ads
│   └── form_fields_page.py     # страница с формой (пункт 5)
├── tests/                      # тесты
│   ├── conftest.py             # фикстура driver + скриншот при падении → Allure
│   ├── test_calendars.py
│   ├── test_modals.py
│   ├── test_ads.py
│   └── test_form_fields.py
├── pytest.ini
├── requirements.txt
├── .gitignore
└── README.md
```

Принципы:
- **Page Object**: локаторы и действия лежат в `pages/`, в тестах только сценарий и проверки.
- **Явные ожидания** (`WebDriverWait`) вместо `sleep` — тесты не зависят от скорости сайта.
- **Точные проверки**: сравниваем с конкретным ожидаемым значением (месяц, год, полная дата), а не «значение изменилось».
- **Изоляция**: каждому тесту — новый браузер.
